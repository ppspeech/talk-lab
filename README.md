# Talk Lab

CAS / motor speech session tracker (NDP3-based) by Pei-Pei Hsing, CPSP.

- Session tracking with Today's targets and goals
- Kids' games with a "said it" word card, sticker book and fish tank
- Bridge it (VC + word) with Hold the sound
- Word-shape quick sets (VC, CV, CVCV, CVC)
- Mouth map: placement, voice and air for 21 sounds
- Family page with progress and a "how to make the sound" guide

Live: https://claude.ai/artifact/AmzsLjh4QL3KbAatCHyjKz

Single-file app: open `index.html`.
